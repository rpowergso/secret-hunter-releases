# Secret Hunter

Secret Hunter is an unofficial multiplayer minigame for Minecraft Java Edition 26.3 servers running Paper. Runners race to defeat the Ender Dragon while hidden hunters track them with a compass.

**Status:** Beta in testing. Download pending.

Maintained by rpowergso with AI assistance. Inspired by [zorato’s Secret Hunter series](https://www.youtube.com/watch?v=JaN_pfpr1tE).

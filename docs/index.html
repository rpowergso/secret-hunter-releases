Paper server plugin

Secret Hunter

Race to defeat the Ender Dragon while a secret hunter tracks your team across dimensions.

Download the 1.0.14 beta

How a round works

Runners
Defeat the Ender Dragon before the hunters eliminate the team. Share locations through the game’s built-in commands.
Hunters
Use a compass to cycle between living runners and see which dimension the selected runner is in.
Operators
Choose the number of hunters, configure the countdown and regenerate hunt worlds for a fresh seed.

Server requirements

Minecraft Java Edition 26.3 with Paper 26.3 and Java 25 or newer on a dedicated server. Two or more players are needed to start a round.
